# Правила для Claude в этом репозитории

## Видео (YouTube Shorts)

- **Каждое видео — с хорошей обложкой.** Это требование владельца канала, не пропускать.
  - Делать отдельный файл обложки `out/<имя_видео>_cover.png`, 1080×1920, рядом с видео.
  - Первый кадр видео должен совпадать с обложкой (или быть таким же сильным), потому что в ленте
    Shorts первый кадр работает как обложка.
  - Обложка: одно яркое изображение-герой крупно, 2–4 слова очень крупным контрастным текстом
    (жёлтый/белый с чёрной обводкой), текст в верхней или средней трети — не внизу, где его
    закрывает интерфейс Shorts.
  - Текст обложки не должен повторять заголовок: проверять пару через
    `python3 skills/yt-package/title.py --title "..." --thumb "..."`.
  - Перед отправкой посмотреть обложку глазами (Read на PNG) и показать её пользователю вместе с
    видео.
- **В конце каждого видео — реклама канала** (последние ~4 секунды), это требование владельца канала:
  «Ещё больше интересных фактов о животных — на канале!» + название канала «Интересные факты о
  животных», аватарка, кнопка «ПОДПИСАТЬСЯ», персонажи-животные. Голосом, если голос тот же, что в
  ролике; иначе только текстом. Готовый рендер концовки: `scratchpad/.../animals/outro.py` (пересоздать
  при новой сессии).
- **Озвучка: Piper, голос «Дмитрий»** (`ru_RU-dmitri-medium`, лицензия датасета CC0), выбран владельцем
  канала. Установка: `pip install piper-tts`, модель с huggingface.co
  (`rhasspy/piper-voices/ru/ru_RU/dmitri/medium`). Темп `--length-scale 0.92`. Озвучивать по фразам,
  чтобы субтитры совпадали с голосом. Не использовать голос «Руслан» (запрет коммерции).
- Пользователь общается по-русски — отвечать по-русски.
- Не выдумывать факты; помечать то, что не проверено.
- В описании указывать, что иллюстрации сгенерированы ИИ, и напоминать про галочку
  «Изменённый или синтетический контент».
